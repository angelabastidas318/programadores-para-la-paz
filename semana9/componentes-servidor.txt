Sistema operativo:
Es el software que administra los recursos del computador o servidor. Permite que las aplicaciones funcionen correctamente y coordina las tareas del sistema.

Node.js:
Es un entorno de ejecución que permite utilizar JavaScript fuera del navegador. Se emplea para desarrollar y ejecutar servidores web.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor. Define las rutas y respuestas que recibirán los usuarios cuando accedan al servicio.

Puerto:
Es un canal de comunicación utilizado por el servidor para recibir y enviar información. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre la actividad y los eventos del sistema. Facilitan la supervisión y la solución de problemas.
